# Quantic Studio

Quantic Studio is an open engineering platform by Quantic Engineering Limited. Electrical engineering is the first discipline, with focused workbenches sharing project data, units, contracts, reports, and solver adapters.

## Status

Phase 0: repository foundation and the first verified electrical studies are being established.

## Tests

Run the test suite from the repository root:

```sh
uv sync
uv run pytest
```
