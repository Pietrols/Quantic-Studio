  5a. Short circuit (WP-1.3, adapters/pandapower/shortcircuit.py and pandapower 3.5.6 source)
  Voltage factor c. Engine (build_bus._add_c_to_ppc): above 1 kV c_max 1.10, c_min 1.00; below 1 kV at
    6% c_max 1.05, c_min 0.95; at 10% c_max 1.10, c_min 0.90. This matches the 2016 Table 1 values Peter
    quoted. Kasikci Table 1.1 (p. 8, 1997 draft): LV c_max 1.05 (+6%) or 1.10 (+10%), but one LV c_min of
    0.95 for both tolerances; MV and HV 1.10 and 1.00. Das Table 8-2 (IEC 909:1988): LV 230/400 V 1.00 and
    0.95, other LV 1.05 and 1.00, MV/HV 1.10 and 1.00. The LV minimum is therefore edition-dependent, and
    the adapter is right to block c_min at 10% tolerance until the 2016 text is a cited source.
  Exact 1 kV boundary. Both books put 1000 V in the LV band (Kasikci Table 1.1 "100 V to 1000 V"; Das
    Table 8-2 "100-1000 V"). pandapower classifies only vn_kv < 1 as LV, so at exactly 1.0 kV it applies
    the MV factors. The current diagnostic ("undocumented exact 1-kV boundary") should instead say that
    the sources put 1 kV in LV and the engine does not. It must stay unavailable while pandapower computes c.
  K_T. Kasikci eq. 9.14 (p. 79): K_T = 0.95 c_max/(1 + 0.6 x_T), with x_T on the transformer rating, as
    implemented. Neither book distinguishes maximum and minimum cases. pandapower sets K_T = 1 for minimum
    faults, citing IEC 60909-0:2016 clause 6.3.3 (build_branch._transformer_correction_factor). For a
    minimum duty, K_T = 1 gives the larger impedance and so the smaller (conservative) current. Remains
    unavailable: needs the 2016 clause or Peter's decision.
  K_G. Kasikci eq. 9.3 (p. 76) and Das eq. 8.11 (section 8.4.1): K_G = (U_n/U_rG) c_max/(1 + x''d sin phi_rG).
    pandapower ppc_conversion._add_gen_sc_z_kg_ks computes vn_net/(vn_gen(1 + pg)) cmax/(1 + xdss sin phi),
    which matches; the voltage_source.html documentation prints the ratio inverted. The ratio U_n/U_rG
    can be unlocked. Nonzero p_G stays blocked: neither book gives (1 + p_G) for a directly connected
    generator (Kasikci has it only for power-station units, eq. 9.11, p. 78).
  Thermal factor m. Kasikci eq. 13.2 (p. 117): m = [exp(4 f T_k ln(kappa - 1)) - 1]/(2 f T_k ln(kappa - 1)),
    n = 1 far from generators (eq. 13.1). Its limit as kappa approaches 2 is 2, and Kasikci Fig. 13.3a
    (p. 118) shows m approaching 2 at short T_k for kappa = 1.95. Recomputed: kappa = 1.99 gives m = 0.862
    at T_k = 1.0 s and 1.812 at 0.1 s. pandapower (currents._calc_ith) sets m = 0 for kappa > 1.99, which
    understates Ith; it also hardcodes f = 50. The adapter already blocks both cases and cross-checks the
    engine with its own expm1 evaluation of the same equation. Both can be unlocked by evaluating the
    book equation in the adapter (with f from the request, and the kappa = 2 limit m = 2).
  Conductor temperature. Kasikci p. 12 gives a factor of 1.24 for a 20 to 80 C rise, which implies
    0.004 per K (1 + 0.004 x 60 = 1.24). That matches the pinned implementation, not the 0.04 printed on
    the pandapower documentation page, so minimum-case end temperatures other than 20 C can be unlocked.
  Peak current. Kasikci eq. 11.22 and 11.23 (p. 98) match the adapter (kappa = 1.02 + 0.98 exp(-3R/X)).
    Meshed networks (methods A, B, C, p. 98) remain unavailable; unlocking needs a check of which method
    pandapower implements.
  Spot check of examples/shortcircuit by hand: hv max Ik'' 28.87 kA, ip 71.28 kA, Ith 29.36 kA; lv max
    Ik'' 9.659 kA; hv min Ik'' 14.43 kA. All agree with the report.

  5b. Motor start (WP-1.4)
  Method: I_r = P_shaft/(sqrt(3) U eta cos phi_r); |Z_LR| = U/(sqrt(3) k_LR I_r) at the locked-rotor angle;
    added as a constant-admittance shunt S = U_bus^2/conj(Z); dip = 100 (V_pre - V_LR)/V_pre. This is the
    blocked-rotor (s = 1) input impedance of Fitzgerald section 6.6.2, eqs. 6.47 to 6.51 (pp. 333-334):
    R from blocked-rotor power, X from blocked-rotor reactive power. Fitzgerald (p. 333) also notes that
    saturation changes the blocked-rotor impedance at starting currents, consistent with the stated
    assumption that this is a steady locked-rotor snapshot, not a run-up study.
  Independent reference: test_independent_complex_voltage_divider computes the bus voltage by complex
    voltage division in ohms, independently of the adapter, over four base and motor-voltage
    combinations, plus a case with retained shunt admittance. Accepted as independent.

  5c. Reactive limits (WP-1.1)
  Glover section 6.5 (p. 352) and section 6.6 (p. 356): when Q_Gk exceeds its limit, the bus becomes a
    load bus with Q_Gk fixed at the limit and its voltage is recomputed. The adapter uses pandapower
    enforce_q_lims, which does this, and emits one GENERATOR_Q_LIMIT diagnostic per limited generator.
    The hand reference V = (1 + sqrt(1 + 4XQ))/2 for a lossless jX link with P = 0 is correctly derived.
