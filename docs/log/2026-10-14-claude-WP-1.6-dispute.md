summary: Phase 1 milestone audit. The web unit tests fail on Node 25 and later, which is what Peter's Mac runs (Node 26.7.0), because the repository does not pin a Node version and Node 25+ defines a global localStorage that shadows jsdom's. CI passes only because it pins Node 24.
evidence: |
  Commands, on a clean worktree of main at 3f073b3 with Homebrew node 26.7.0 and pnpm 11.25.0:
    pnpm install --frozen-lockfile
    pnpm --filter qe-web test
  Expected: 15 passed, as in CI (setup-node node-version '24').
  Actual: Test Files 1 failed | 1 passed (2); Tests 4 failed | 11 passed (15).
    All four failures are in apps/web/tests/app.test.tsx at line 25, localStorage.clear():
    "TypeError: Cannot read properties of undefined (reading 'clear')", preceded by the Node warning
    "localStorage is not available because --localstorage-file was not provided".
  Confirmation that this is the runtime, not the code under test:
    NODE_OPTIONS=--no-experimental-webstorage pnpm --filter qe-web test   -> 15 passed (15)
    the same command under Homebrew node@24 (24.21.0)                      -> 15 passed (15)
  Also observed under Node 26: playwright install chromium downloads 129.7 MiB and then stalls during
  extraction; under node@24 it completes and e2e passes (2 passed).
  Proposed resolution: pin the supported Node major for local use and make the test independent of
  the host global (see the audit log, proposed fix WP F2).
