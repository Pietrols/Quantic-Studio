summary: Follow-up requested by Peter. The textbook solver now stamps each shunt into the Y-bus diagonal as a constant admittance and no longer treats it as specified power, per docs/specs/network.md ("Shunt values are specified as power at nominal bus voltage, with positive values denoting consumption"). The stamp is y = (p_mw - j q_mvar) / base_mva, not (p_mw + j q_mvar) / base_mva as written in the request: a shunt consumes S = V conj(yV) = conj(y)|V|^2, so the requested sign would turn a capacitor (q_mvar < 0) into an inductor. The shared verifier tests/fixtures/power/verify.py had the same constant-power assumption and was corrected the same way, and tests/fixtures/power/test_fixtures.py now expects five networks; both edits are required by the new fixture and sit in the fixture tree Peter authorized for this follow-up.
