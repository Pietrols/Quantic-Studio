`atlas/` contains the engineering software research atlas and catalogue.

`decisions/` contains architecture decision records that explain important technical choices and their consequences.

`learning/` contains beginner-friendly explainers for the concepts behind the platform.

`log/` contains one immutable record for each work-package status event.

`sources/` contains citations and provenance records for external sources. `sources/entries/` holds one YAML citation record per source.

`specs/` contains human-readable explanations and examples for the shared data contracts.
