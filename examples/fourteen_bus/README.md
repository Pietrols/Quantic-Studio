# Fourteen-bus original example

This directory is a metadata-only project template. Its project manifest names `network.json`, while the authored cross-check network is maintained at `tests/fixtures/power/fourteen_bus_original/network.json` so fixture tests can validate it without copying a second source of truth.

Run `uv run pytest tests/fixtures/power` to validate the original fixture set. This example contains no downloaded or cached network data and has no published solution.
